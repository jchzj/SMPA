# SMPA
Matlab Code


The code is run in Matlab.

Main.m is used to run SMPA algorithm.

fun-compute-gradient.m  can compute the gradient of the variable.

fun-compute-obj-value.m is used to compute the objective function.

fun-init.m can select the initial value.

fun-PSIB-GSD.m is the code of  Algorithm1.


 All experimental data have been saved in the folder all-figure-mat, plot-all-figure.m can reproduce all the figures.
